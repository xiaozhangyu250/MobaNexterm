# Security Policy

## Reporting a Vulnerability

Do not open a public issue for vulnerabilities that may expose credentials,
private keys, remote hosts, or user files.

Report the issue privately through GitHub Security Advisories for this
repository. Include reproduction steps, affected versions, and the potential
impact. Remove real credentials, hostnames, and private data from reports and
logs.

Security fixes are prioritized according to severity. Supported versions are
the latest release and the current `main` branch.
