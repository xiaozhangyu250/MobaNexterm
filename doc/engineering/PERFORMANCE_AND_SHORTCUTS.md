# 远端性能摘要与快捷指令

## 范围与使用

- 底栏对当前已连接终端显示远端 CPU、内存、根分区 `/` 的占用率。悬停内存/磁盘可查看已用/总量，CPU 可查看 1 分钟负载。CPU 首次需要两次采样；缺少指标显示 `—`，失败显示不可用，断连后移除。
- 左侧新增“快捷指令”。添加、编辑均打开非模态原生窗口，位置跟随发起操作的主窗口所在屏幕；可继续操作终端并复制内容。
- 指令包含名称、执行目录、多行命令和可用范围。范围为全局或一个已保存 SSH 会话对象，按稳定会话 ID 关联，不按名称或 IP 猜测；相同 IP 的不同会话也能分别配置。
- 执行目录留空使用当前目录；支持绝对路径、`~` 和 `~/…`。切换目录失败时整段命令不执行。成功后目录变化保留在当前 Shell。
- 面板按当前激活终端过滤按钮。点击在该终端的现有 Shell 环境执行；不会开启新的 SSH exec 任务或自动加载其他环境。支持多行、引号、变量、注释、heredoc。请在空白 Shell 提示符处使用；Vim 等备用屏幕程序打开时拒绝执行，断连时按钮禁用。
- 编辑器提供轻量语法高亮、Ctrl+S、未保存关闭保护、基本字段校验和手动 Bash 语法检查。检查调用本地 `bash --noprofile --norc -n`，不执行命令，不检查远端程序/目录是否存在；其他 Shell 的语法应自行确认。语法检查是辅助工具，不阻止用户保存其他 Shell 方言。
- 支持重命名、修改、删除指令；保存后同步所有窗口。指令存储在 Electron 用户配置目录下的 `shortcuts.json`，不是凭据保险库，不宜在脚本中硬编码密码。

## 架构

1. `remoteMetrics.ts` 使用独立、无 PTY 的 SSH exec 通道读取 Linux `/proc/stat`、`/proc/meminfo`、`/proc/loadavg` 和 `df -Pk /`。不需要 sudo 或远端常驻服务。
2. CPU 为相邻采样计数差，guest 不重复计数；空闲包含 iowait。内存使用 `MemTotal - MemAvailable`。磁盘百分比采用 `df` 的根文件系统占用率，并非所有挂载点合计。
3. 正常每 5 秒采样，初次 CPU 追加一次快速采样；失败 10 秒后重试。窗口隐藏时暂停发起采样，按连接实例隔离 CPU 基线，去重同连接并发请求。采样超时 4 秒、返回上限 64 KiB；旧连接结果不覆盖新连接，不影响交互 Shell。
4. `ShortcutManager` 在主进程统一持久化，校验主机范围及字段，使用版本号检测并发编辑和已删除项。IPC 只暴露限定的 CRUD、检查、打开窗口和执行接口。
5. 执行前重新读取保存的指令，校验终端所属窗口、连接状态和主机范围。多行内容编码为单个物理输入行，由当前 Shell 解码执行，避免 heredoc 或引用被终端逐行输入破坏。此输入封装面向 Bash/Zsh/POSIX 兼容 Shell，未验证 fish。
6. 非模态工具窗口复用多屏放置和未保存关闭保护。保存新建指令后重设窗口索引，允许继续创建另一条指令；编辑已有指令复用对应窗口。

## 验证

- 单元/服务回归：CPU 计算、缺失值、计数回退、超时、响应上限、断连及晚到通道清理；采样去重和窗口所有权；全局/主机过滤；指令持久化、并发冲突和删除保护；多行/heredoc、中文与引号目录、cd 失败、HOME 展开；语法检查不执行脚本；高亮保持原文。
- Electron + 临时 SSH 服务：性能摘要、失败后清除旧数据、断连、独立编辑窗口及屏幕定位、语法错误与成功结果、实际 Bash 多行执行、全局/主机范围切换、备用屏幕保护、配置持久化。
- 原有终端、目录跟随、远程编辑器、文件自动刷新和断线回滚流程继续执行回归。

## 边界

监控面向 Linux；受限 SSH 服务禁止 exec 或系统缺少 `/proc`/`df` 时允许部分指标缺失。快捷指令不能可靠判定所有普通屏幕交互程序是否正在等待输入，因此用户需回到空白 Shell 提示符处执行。Bash 语法检查不等同于命令执行成功或机器人运行结果正确。


## 快捷指令导入与导出

左侧“快捷指令”页卡增加“导入指令”和“导出指令”：

1. 导出列表包含所有保存的指令（包括其他主机的指令），支持全选/全不选、逐条勾选及展开目录和命令预览。确认选择后，通过系统保存对话框导出 JSON。
2. 导入先通过系统文件选择器读取 JSON，再预览、勾选所需条目。主机专属指令必须指定本机 SSH 会话或明确改为全局；支持批量设置所选条目的范围。全局指令默认保持全局，也可改为指定主机。
3. 导入始终创建新记录，生成新的本机 ID。同名条目依次编号为 `名称 (2)`、`名称 (3)`，不会覆盖或合并已有命令；重复导入也采用此行为。
4. 一次导入整批校验后统一保存。文件格式/版本不支持、字段非法、目标主机被删除时保留原配置。取消选择文件或取消预览不会写入，导入不会执行任何脚本。
5. 文件只含指令原文、目录和范围标签，不含会话 ID、IP/用户名字段、密码、密钥等连接信息；用户自行写在命令里的内容会原样导出。

文件格式示例（UTF-8，可带 BOM；多行指令使用 JSON 换行转义）：

```json
{
  "format": "mobanexterm-shortcuts",
  "version": 1,
  "shortcuts": [
    {
      "name": "日志检查",
      "directory": "~/robot_ws",
      "command": "pwd\njournalctl -u robot --no-pager -n 100",
      "scope": { "kind": "host", "label": "机器人 A" }
    },
    {
      "name": "磁盘检查",
      "directory": "",
      "command": "df -h /",
      "scope": { "kind": "global" }
    }
  ]
}
```

`scope.label` 仅供辨认来源，不自动匹配本机主机。限制每份文件 1–500 条指令、最大 2 MiB；单条命令继续沿用 16,384 字符限制。未知附加字段不写入本地配置；Windows CRLF 命令文本转换为 LF。导出先写入同目录临时文件，再替换目标文件，避免写入失败导致已有导出文件被截断。

代码边界：`shared/shortcutTransfer.ts` 负责便携格式、字段白名单及重名规则；主进程 `shortcutFiles.ts` 负责有界文件读写；`ShortcutManager.importCopies` 负责整批校验和一次保存；Renderer 负责选择、预览和范围映射，IPC 再次验证所有写入。

新增验证包括文件往返、多行/中文/引号、版本与字段错误、数量/大小限制、UTF-8/BOM、外来 ID/附加字段剥离、同名副本、无部分写入；桌面测试覆盖选择性导出/导入、取消、主机映射、预览和持久化。桌面测试用替身提供原生文件对话框返回值，实际读写临时 JSON 文件，不接触用户配置。截图位于 `test-results/shortcut-export.png` 和 `test-results/shortcut-import.png`。
