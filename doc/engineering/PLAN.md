# 稳定性与工作台改造计划

## 设计原则

保留现有 SSH、SFTP、归档下载、权限编辑、主题和本地化功能。优先修复可定位的根因；将终端协议、窗口几何、目录请求协调和编辑器保存拆为可测试模块。桌面工作台无需网站框架。

## 本轮实施（已完成，验证见 VALIDATION.md）

1. 终端：流式 UTF-8、准确的初始 PTY 尺寸、连接生命周期与 SFTP 解耦、输出背压、Unicode 字宽、回滚搜索、活动标签焦点、ANSI 配色。
2. 窗口：屏幕热拔插和工作区尺寸变化时完整收纳窗口、动态最小尺寸、保持最大化状态、F11 全屏。
3. 文件：当前目录及已展开目录定时刷新，前后台感知、请求去重、旧会话响应隔离、失败保留列表。
4. 编辑器：独立原生窗口、搜索/替换、行列状态、关闭脏文件提示、并发修改检测、同目录临时文件原子替换。
5. 工作台：一致的间距和配色、可调侧栏、会话过滤、实用快捷键、真实连接状态。
6. 工程：协议/生命周期/文件安全回归测试、统一检查命令、CI 构建、人工验收矩阵。

## 后续功能路线（需要单独实现与验收）

- P1：主机密钥指纹信任管理、SSH Agent 配置、会话分组/导入 OpenSSH config、跳板机与本地/远程端口转发。
- P1：传输取消、限速、失败重试和断点续传；大目录虚拟列表与任务持久化。
- P2：分屏、会话日志导出与脱敏、远程进程/服务监控。CPU/内存/根分区摘要及用户快捷指令已实现，见 [设计与验证](PERFORMANCE_AND_SHORTCUTS.md)。
- P2：本地 PTY、串口、代理配置；Wayland/X11 和不同缩放比例的发行版发布矩阵。

不以未测试功能数量替代可靠性。尚未实现的能力不在 UI 中显示为可用。

## 性能摘要与快捷指令增量

已实现独立 SSH 通道性能采样、底栏摘要、全局/主机范围快捷指令、独立编辑窗口、高亮/语法检查、当前终端多行执行和回归测试。实现边界与使用说明见 [PERFORMANCE_AND_SHORTCUTS.md](PERFORMANCE_AND_SHORTCUTS.md)。
