# 改造与验收记录

## 已实现的变化

- 编辑器新窗口按发起操作的主窗口所在屏幕定位，在窗口附近居中并限制在工作区内；已打开的编辑器保留用户调整的位置。
- 断连与连接错误在终端末尾追加红色提示和上下分隔线，无遮罩；支持 R 重连。断连后仍可滚动、搜索和选择旧输出，重连保留回滚记录；全屏程序断连时将最后屏幕以文本保留至正常回滚缓冲区。

- 终端使用流式 UTF-8 解码，跨 SSH 数据包的中文和 emoji 不再被逐包解码为替换字符。OSC 7 目录元数据也可跨包解析。
- xterm 完成挂载和字体度量后才连接，远端 PTY 接收实际行列数；连接期间保存最新尺寸。活动标签获取焦点，隐藏终端不参与键盘交互。
- xterm Unicode 11 字宽、完整 ANSI 16 色、明亮色在浅色主题下可读；增加 Ctrl+Shift+F 搜索。没有通过正则重写远端输出，Vim 控制序列原样保留。
- 输出在 256 KiB 待解析字符时暂停 SSH 流，降到 64 KiB 后恢复。ack 包含连接标识并验证窗口来源，旧连接不会影响重连后的流控。
- Shell 与 SFTP 启动解耦，Shell 总启动超时 25 秒，SFTP 启动超时 10 秒；SFTP 故障不关闭 Shell。
- 移除了原有延迟 `stty -echo` / 多次注入的流程。Bash/Zsh 目录集成默认开启，在连接开放输入前一次安装；保留已有提示符钩子及上一条命令退出码，并编码路径中的 URL 特殊字符。已保存的关闭设置仍受尊重，文件面板显示等待目录报告的原因，并提供启用并重连入口。服务器已有 OSC 7 时可关闭集成。恢复上次目录需要启用集成。
- 文件列表每 3 秒刷新当前和展开目录，窗口不可见时暂停；返回前台刷新。请求去重、代际隔离、取消旧轮询、失败保留原列表。
- 独立原生编辑器支持多个文件窗口、搜索、区分大小写、替换/全部替换、保存快捷键、行列状态、脏文件关闭提示。保存过程中继续编辑时，后续修改仍标记为未保存。
- 文本读取流式限制为 2 MiB，拒绝二进制和无效 UTF-8；保留 BOM 与常规 CRLF。保存检查外部修改，独占创建同目录临时文件，校验大小、保留 POSIX 权限和所有者，再通过 OpenSSH 原子重命名替换。不支持该扩展或无法保留元数据时报告错误，不回退到直接截断原文件。
- 多屏几何恢复同时处理完全离屏、部分可见、分辨率缩小及负坐标屏幕，调整最小尺寸，尽量恢复最大化/全屏状态。
- 工作台更新、会话筛选、可调整侧栏、Ctrl+Tab / Ctrl+Shift+Tab、Ctrl+Shift+K 新会话、F11 全屏、真实连接信息状态栏。

性能摘要、快捷指令及选择性 JSON 导入/导出的设计与专项验收见 [PERFORMANCE_AND_SHORTCUTS.md](PERFORMANCE_AND_SHORTCUTS.md)。

## 范围与已知限制

- 本轮是可验证的稳定性与工作流改造，不能据此宣称所有发行版、窗口管理器及远端应用已达到原生终端兼容程度。物理显示器热拔插未在本次环境中实际执行。
- 目录刷新是低频轮询，通常 3 秒内反映变化，不是服务端文件系统事件订阅；大量展开目录或高延迟连接可能更慢。
- 外部修改检测是乐观比较，不能提供与其他远端程序之间的原子 CAS。临时文件替换不保留扩展 ACL、xattr 或硬链接关系，此类文件使用远端专用编辑流程。
- 不支持 OpenSSH `posix-rename` 的 SFTP 服务可阅读文件，但内置编辑器拒绝不安全保存。
- Unicode 11 字宽改善常用 CJK/emoji；复杂字素簇和远端不同 wcwidth 版本仍需兼容测试。
- 原项目已有的主机密钥验证缺失、凭据明文回退、未限制递归传输的范围等问题未在本轮整体重写；已列入后续工程优先项。现有 Electron 33 与依赖链应另做升级和安全验证，本轮没有进行未经验证的批量主版本升级。
